# LAV Interiors — Design System

## Concept
Old Money / Quiet Luxury / Editorial architecture magazine. One visual code across every block.

## Forms
- Default: sharp rectangles with double-line molding (`border` + `outline`, offset ~6–8px).
- `border-radius: 0` (max 2px) on cards, buttons, chips, tabs, inputs.
- Exceptions only: floating quick-rail icons; About quote callout (`.signature`).

## Typography
- Serif (Cormorant): brand + H2.
- Script (Italianno): one accent phrase in every major section.
- Sans (Manrope): nav, labels, body — same size/hover for all header links including “50 options…”.

## Color
- Base: warm paper `#EFE9DF`, ink `#1A1714`, muted stone.
- No sudden green/sage accent blocks. Accents = warm graphite / soft gold line.

## Backgrounds
- Unique image per section from `фоновые/1 (n)` — never reuse.
- Treatment: keep color, cream wash, film grain, muted for text.
- No CSS `grayscale` on section backgrounds.

## Image ratios
- Portfolio cards: strict **3:4** (vertical — mobile + Pinterest).
- Process / other content visuals: **4:3** unless noted.

## Portfolio filters
1. Categories: All · Interiors · Architecture & Houses · Landscape · Public/Boutique · Lighting/Details
2. Styles: live tags (Quiet Luxury, Warm Minimal, Organic Modern, …). New styles can be added when content needs them.
3. Grid is adaptive — any number of cards per style/category is allowed.
